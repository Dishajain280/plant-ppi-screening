A harness for screening plant protein interactions by structure

Resolve the proteins, batch prediction jobs inside a free quota, parse the confidence metrics, and score the ranking against known positives and honest negatives — with a guard that refuses to report numbers on labels nobody verified.

What the harness does

four commands, one pipeline
1

Resolve

Gene symbols to UniProt entries, with a synonym fallback for names like AGB1 and explicit accession pinning where two genes share a symbol.

2

Validate labels

Rejects duplicate pairs, placeholder sources and a negative class that is mostly easy decoys — the three ways a benchmark looks solid and means nothing.

3

Batch

Jobs inside the 30-per-day quota and the 5,000-token cap. Over-budget pairs are skipped with a printed reason, never dropped silently.

4

Score

ipTM and chain-pair PAE into a ranked table, AUC with bootstrap intervals, and the calibration gap reported separately from the benchmark.

Status

stated plainly on purpose

Built and tested

  • UniProt resolution with caching and ambiguity handling
  • Label validation with a hard block on unverified scoring
  • Quota-aware batching with token accounting
  • Metrics with bootstrap intervals and a dependency-free figure
  • 36 offline tests, running in CI on every push

Not done yet

  • Literature verification of the remaining labels
  • AlphaFold Server runs — no API, 30 jobs a day, manual upload
  • A measured AUC on a frozen label set
  • Experimental validation by Y2H or BiFC, which is the point

Quickstart

# resolve proteins, check labels, build a batch
python cli.py resolve
python cli.py check-labels
python cli.py batch

# upload batches/*.json at alphafoldserver.com, download the results
python cli.py ingest --results results/
python cli.py evaluate --results results/scores.csv

No third-party packages. Python 3.10+ standard library only. The evaluator exits with status 2 while any included label is unverified.
